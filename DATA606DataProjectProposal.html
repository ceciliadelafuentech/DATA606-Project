maple_states_weather <- weather %>%
  filter( #Maine, Michigan, New Hampshire, New York, Pennsylvania, Vermont, and Wisconsin
    state_code %in% c("017", "020", "027", "030", 
                      "036", "043", "047"),
    division == "0", #0 indicates an area-averaged element
    element == "02", # 02 = Average Temperature
    year >= 2001,
    year <= 2026
  )

Average sugaring season temperature and add state column

maple_states_weather <- maple_states_weather %>%
  mutate(
    avg_temp = rowMeans(
      select(., feb, mar, apr), #average temperature with sugaring months
      na.rm = FALSE
    )
  ) %>%
  mutate(
  state = recode(
    state_code, #create new state column
    "017" = "Maine",
    "020" = "Michigan",
    "027" = "New Hampshire",
    "030" = "New York",
    "036" = "Pennsylvania",
    "043" = "Vermont",
    "047" = "Wisconsin"
  )
)

Research question

Is average temperature during the maple sugaring season (February–April) associated with syrup yield per tap across seven U.S. states from 2001–2026?

Null hypothesis (H₀): There is no association between February–April average temperature and maple syrup yield per tap, after accounting for year and state.

Alternative hypothesis (H₁): There is an association between February–April average temperature and maple syrup yield per tap, after accounting for year and state.

Cases

Each case represents one state in one year. The dataset includes seven maple-producing states (Maine, Michigan, New Hampshire, New York, Pennsylvania, Vermont, and Wisconsin) across 26 years (2001–2026), for a total of 182 observations.

Data collection

This project will use two publicly available datasets:

  1. USDA National Agricultural Statistics Service (NASS): Annual maple syrup yield, measured in gallons per tap, for the seven selected states from 2001–2026.

  2. NOAA nClimDiv: Monthly statewide average temperature data. Observations for February, March, and April will be used to calculate the average temperature during the sugaring season for each state and year.

The datasets will be combined by state and year so that each observation includes the corresponding yield and average temperature.

Study type

This is an observational study because the project uses historical yield and weather data. The analysis will examine associations rather than establish causation.

Variables

Response variable:

  • Maple syrup yield per tap: Numerical variable, measured in gallons per tap.

Explanatory variables:

  • Average sugaring-season temperature: Numerical variable, calculated as the average of February, March, and April temperatures for each state and year. This is the primary explanatory variable.

  • Year: Numerical variable ranging from 2001–2026.

Categorical variable:

  • State: Categorical variable identifying the seven states
